# GTM-engineering

Репозиторий инструкций для агентов, которые квалифицируют лиды и пишут первые сообщения. Один и тот же каркас используется для разных компаний. Правила каждой компании лежат в своей папке и не смешиваются.

Агент начинает с [AGENTS.md](AGENTS.md). Оттуда он попадает в один файл: либо квалификация, либо сообщения.

## Как устроено

```text
AGENTS.md                      маршрутизатор: компания и задача
companies/
  hive-hr/
    AGENTS.md                  напоминание внутри папки компании
    validate.md                квалификация лида
    message.md                 Message и Followup2
  _template/                   пустой каркас следующей компании
```

Сейчас заведена одна компания, Hive HR. Квалификация лежит в `validate.md`, сообщения в `message.md`. Других компаний нет.

Инструкции живут только в этих файлах. Google Doc не открывать и не обновлять.

## Как поставить задачу

В запросе должны быть компания и задача.

- «Квалифицируй лид для Hive HR» открывает `companies/hive-hr/validate.md`.
- «Напиши Message и Followup2 для Hive HR» открывает `companies/hive-hr/message.md`.

Агент квалификации не пишет письма. Агент писем не пересматривает статус.

## Новая компания

Скопируй `companies/_template` в `companies/<slug>`, перепиши оба файла под эту компанию и добавь строку в таблицу в `AGENTS.md`. Пока строки нет, агенты компанию не берут в работу. Имена `validate.md` и `message.md` не меняются: маршрутизатор ищет именно их.
