# {Название компании}

Рабочий документ со строками: {ссылка на Google Sheets}. Пока ссылки нет, строки неоткуда брать и некуда записывать. В инструкции напиши, какая строка считается незаполненной: агент начинает с неё и не переписывает уже заполненные.

Это каркас, не рабочая компания. Пока оба файла не переписаны и компания не добавлена в таблицу корневого `AGENTS.md`, задачи по ней не выполнять.

Схему рабочих колонок сначала создать/сверить по **общему правилу** корневого `AGENTS.md`: исходный импорт неизменен, рабочие колонки только справа, минимум полей без выпадающих списков, а обязательное поле обычного LinkedIn-профиля — `<PREFIX>_LI_link` (если еще нет). Агент проверяет соответствие публичного `/in/`-профиля человеку из исходной ссылки, а не механически меняет URL. Актуальные заголовки и допустимые поля для квалификации указать в `validate.md`; поля сообщений — в `message.md`.

После заполнения оставь в этой папке ровно два рабочих файла плюс этот маршрутизатор.

| Задача | Файл |
| --- | --- |
| Квалификация лида | [validate.md](validate.md) |
| Сообщение и повторное касание | [message.md](message.md) |

Имена файлов не меняй. Агент открывает только один из них.
