# RefurbishBox

Компания: RefurbishBox. Здесь живут инструкции для поиска и работы с брендами, продающими собственные физические товары в США. Правила HiveHR сюда не переносятся.

Рабочая Google Sheets: [RefurbishBox - лиды](https://docs.google.com/spreadsheets/d/1Pn6LWcW3OBHisSamE4Q2tqj1IUQry9SGTZzodYgxhb8/edit?gid=0#gid=0).

**Первый экспорт LinkedHelper импортирован 2026-11-06.** Исходные 258 столбцов `A:IX` только для чтения. По просьбе пользователя таблица упрощена до **10** выходных колонок `IY:JH`: семь `RB_*` в `IY:JE`, три поля сообщений `Message`, `Followup1`, `Followup2` в `JF:JH`. Выпадающих списков нет, все решения агент принимает самостоятельно. Седьмая колонка `RB_LI_link` (`JE`) предназначена для **проверенного публичного LinkedIn URL** из последующей обработки ссылки Sales Navigator `profile_url` в исходной колонке **O**; автоматически переименовывать `/sales/people/` в `/in/` запрещено. Поле пока оставить пустым. Не менять исходные данные и не создавать отдельную таблицу. После новых импортов сверять заголовки по названиям.

## Задачи

| Названная задача | Открыть только | Не делать |
| --- | --- | --- |
| Квалификация / проверка / скоринг | [validate.md](validate.md) | Не читать message.md и не писать сообщения |
| Message / follow-up | [message.md](message.md) | Не читать validate.md, не исследовать заново и не изменять RB_* |

Если задача не названа - уточнить ее. Квалификация сначала проверяет **бренд и товарный бизнес**, затем **человека**. Сообщения используют лишь готовые факты.

Квалификация идет по строкам с пустым `RB_статус`: внутри агента быстрый скрининг компании → глубокая проверка перспективных → проверка человека. Записывать шесть основных полей квалификации, не менять готовые строки без отдельного задания. Поле `RB_LI_link` допускается заполнять позднее только подтвержденным публичным LinkedIn-профилем из ссылки в `O`. В начале пилота приоритет — зарубежные бренды с подтвержденными товарами на Amazon US, но HQ США не жесткое исключение. Переиспользовать подтвержденные сведения компании для разных людей, сохраняя отдельную оценку контакта. `location_name` — география человека, не HQ.
