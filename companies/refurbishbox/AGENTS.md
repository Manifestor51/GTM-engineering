# RefurbishBox

Компания: RefurbishBox. Здесь живут инструкции для поиска и работы с брендами, продающими собственные физические товары в США. Правила HiveHR сюда не переносятся.

Рабочая Google Sheets: [RefurbishBox - лиды](https://docs.google.com/spreadsheets/d/1Pn6LWcW3OBHisSamE4Q2tqj1IUQry9SGTZzodYgxhb8/edit?gid=0#gid=0).

**Первый экспорт LinkedHelper импортирован 2026-11-06.** Исходные 258 столбцов `A:IX` только для чтения. По просьбе пользователя таблица упрощена до **10** выходных колонок `IY:JH`: семь `RB_*` в `IY:JE`, три поля сообщений `Message`, `Followup1`, `Followup2` в `JF:JH`. Выпадающих списков нет, все решения агент принимает самостоятельно. Седьмая колонка `RB_LI_link` (`JE`) предназначена для **проверенного публичного LinkedIn URL** из последующей обработки ссылки Sales Navigator `profile_url` в исходной колонке **O**; автоматически переименовывать `/sales/people/` в `/in/` запрещено. Поле пока оставить пустым. Не менять исходные данные и не создавать отдельную таблицу. После новых импортов сверять заголовки по названиям.

## Задачи

| Названная задача | Открыть только | Не делать |
| --- | --- | --- |
| Квалификация / проверка / скоринг | [validate.md](validate.md) | Не читать message.md и не писать сообщения |
| Message / Followup2 | [message.md](message.md) | Не читать validate.md, не повторять квалификацию, не менять `RB_*` или `Followup1` |

Если задача не названа - уточнить ее. Квалификация сначала проверяет **бренд и товарный бизнес**, затем **человека**. Автор сообщений берет готовую квалификацию и проверяет свежие публичные публикации получателя по `message.md`.

**Алгоритм валидатора:** идти по строкам с пустым `RB_статус`, вначале быстро исключать явно неподходящие компании, затем у перспективных подтвердить собственный бренд, US-продажи и пригодность 1-2 SKU. **Соответствие ICP не требует доказанного operational gap**: неизвестная внутренняя обработка возвратов не делает бизнес неподходящим; подозреваемую потребность не выдавать за факт. Далее оценить импортированного человека по уже имеющимся `current_company`, `current_company_position` и другим данным LinkedHelper, **не открывая LinkedIn для формального повторного подтверждения каждого места работы**. Точечная проверка LinkedIn только при сомнении в текущей компании/роли/US-scope или для подтверждения `RB_LI_link`. Записать шесть основных полей квалификации и при наличии проверенной публичной ссылки `RB_LI_link`; **не писать сообщения**. Второй агент берет итоговую квалификацию, проверяет профиль на свежую авторскую публикацию за 14 дней и пишет только `Message` и `Followup2`. `Followup1` никто не заполняет и не меняет. Не перезаписывать готовые строки; переиспользовать факты одной подтвержденной компании для нескольких контактов. Приоритет - иностранный бренд + Amazon US, но US HQ не исключение; `location_name` - география человека, не HQ.
