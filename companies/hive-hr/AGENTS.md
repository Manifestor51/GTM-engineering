# Hive HR

Рабочий документ со строками лидов: таблица [salesnavigator](https://docs.google.com/spreadsheets/d/1Nyi8FhDPsI5KlLFqXpJFMfcANsQMw3QAQhv0IV8JGYI/edit).

Работаем в этой таблице. Строки читаем из неё и результат записываем в неё же. Другой файл для строк не заводим. Столбцы для работы: IY:JG. Читать и писать только в этом диапазоне. Столбцы левее IY и правее JG не менять. Преобразованная ссылка на профиль в обычном LinkedIn пишется в столбец JD и на всех этапах открывается только она. В Sales Navigator не входить. Начинай с незаполненных строк и иди вниз. Уже заполненные строки не переписывай.

Ты в папке компании Hive HR. Открой ровно один файл.

| Задача | Файл | Что сделать | Что не делать |
| --- | --- | --- | --- |
| Квалификация лида | [validate.md](validate.md) | Заполнить поля HIVE_* и итоговый статус по правилам файла | Не писать Message, Followup1 и Followup2 |
| Сообщение и Followup2 | [message.md](message.md) | Написать Message и Followup2 по уже готовому HIVE_статус | Не менять поля HIVE_* и не переквалифицировать лида |

Задача не названа — остановись и спроси. Второй файл не открывай.
